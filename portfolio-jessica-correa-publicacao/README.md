# jessica corrêa

Site multipage estático do portfólio pessoal, acadêmico e autoral de Jessica Corrêa Pantoja.

## Publicação

O site não exige etapa de compilação. Para publicar no Cloudflare Pages, conecte o repositório e use a raiz do projeto como diretório de saída, sem comando de build.

## Projetos incluídos

Além de `Narrativas em Medicina`, `Aulas — Cursinho Popular` e `Vem pro BICT`, a página de projetos reúne `Pontes Digitais`: podcast realizado no contexto da UFABC, com dois episódios publicados no [Audio.com](https://audio.com/jessicacorrea).

## Ilustrações

O site usa quatro ilustrações originais, de fundo branco e sem texto, em `assets/images/`. Elas são usadas de modo pontual nas páginas sobre, pesquisa, projetos e escritas.

O portfólio declara finalidade pessoal, acadêmica, educacional e não comercial. Nenhuma prévia com marca d'água ou imagem de terceiros é publicada.
